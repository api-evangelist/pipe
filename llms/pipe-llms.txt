# Pipe

> Pipe is an embedded financial OS that lets platforms — vertical SaaS, payment facilitators, and marketplaces — offer capital and cash-flow tools to the small and medium-sized businesses on their platform without those businesses leaving the platform. Its marquee product, Capital, delivers pre-approved funding offers based on transaction data with repayment tied to sales performance. Pipe exposes a REST API plus prebuilt embedded UI components and a Pipe-hosted flow. This is an API Evangelist enrichment profile generated from public pages; the API reference itself lives behind password-gated docs.

## Products
- Capital: Pre-approved funding for SMBs based on transaction data, with flexible sales-linked repayment.
- Embedded UI components: Prebuilt, brand-matched surfaces for the capital experience.
- Pipe-hosted: Zero-code hosted flow driven by warehouse sync or API calls.
